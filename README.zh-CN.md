# learn-llm

[English](README.md) · **简体中文**

从几乎零基础的数学和编程出发，亲手搭建属于你自己的大语言模型，再像生产系统那样把它部署起来提供服务。
所有学习都在浏览器里的同一个页面上完成。

> **状态：早期。**第 00–11 章已经可以学了：从你的第一行 Python，到能在图片任意位置找出数字的卷积网络，再到从故事里学出来的词向量。下一章是第 12 章（预测下一个词）。
> 完整章节规划见 [SCOPE.md](SCOPE.md)（英文）。

## 开始

你需要一台 macOS、Linux 或 Windows 电脑，首次启动时需要联网。不需要 GPU，不用注册账号，也不用自己装 Python。

1. 下载本仓库（[Code → Download ZIP](../../archive/refs/heads/main.zip)）并解压，或者用 `git clone`。
2. 启动课程：
   - **Windows：**双击 `start.cmd`。
   - **macOS / Linux：**在该文件夹中打开终端，运行 `./start.sh`。
3. 浏览器会自动打开课程。选好语言，从第 00 章开始。

第一次启动会安装 [uv](https://docs.astral.sh/uv/)，它会把合适版本的 Python 和课程所需的一切下载到这个文件夹里（大约 1 GB，大部分是 PyTorch）。
只需要等几分钟，而且只有第一次需要。之后每次启动只要几秒。

第 09 章起要用 PyTorch，它能在 Linux、Windows 和 macOS 14 及以上的 Apple 芯片 Mac 上运行。在 Intel 芯片的 Mac 上，课程照样能启动，第 00–08 章都能学。

你的作业保存在 `my-work/` 里，那是每一课属于你自己的副本，更新课程时不会覆盖它。
想把某一章从头再来，删掉 `my-work/` 里对应的文件，重新启动即可。

每一章的末尾都有上一章和下一章的链接；左下角还有一个小导航条（`← 04 · 全部章节 · 06 →`），
在页面任何位置都能切换章节。启动脚本会把导航加进你的副本（包括已经开始做的），不会改动你的答案；
加之前会把原文件备份到 `my-work/.navigation-backups/`，重复启动也不会重复添加。
（直接用 `marimo edit lessons/...` 编辑源课程时没有导航。）如果编辑器在离开某一章时提示你，
说明最近的修改还没保存：稍等自动保存，或者手动保存，再切换。

## 有什么不同

这门课涵盖 Stanford CS231n、CS224N、CS336 以及 [tiny-llm](https://github.com/skyzh/tiny-llm)
推理服务课程的知识，并重新组织成一条连贯的学习路径：

- **需要时再学前置知识。**不先上一整块数学课，每个概念都在用到它的那一页讲。
- **每个主题只讲一次。**反向传播、注意力机制、Transformer 各有一章，后面的章节在此基础上继续。
- **无需配置。**一条命令启动，每道练习的检查都直接在页面上运行。
- **不用来回跳转。**需要的内容都在课程里，外部链接只是可选的扩展阅读。
- **一个不断成长的项目。**你早期写的代码，到最后一章仍在运行。

本课程为原创内容，并非照搬课堂讲义或作业，与 Stanford 及 tiny-llm 作者没有隶属关系。
