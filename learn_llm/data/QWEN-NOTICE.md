# Qwen3-0.6B

Chapter 27 runs a real published model, Qwen3-0.6B by Alibaba Cloud's Qwen team.

- Source: <https://huggingface.co/Qwen/Qwen3-0.6B>, revision `c1899de289a04d12100db370d81485cdf75e47ca`
- Licence: Apache License 2.0
- Files used: `config.json`, `tokenizer.json`, `model.safetensors` (1.5 GB)

The model is **not** bundled with the course. Each learner downloads it once, from the source
above, by pressing a button in chapter 27; `learn_llm/qwen.py` checks every file against its
SHA-256 and keeps it in `my-work/.models/qwen3-0.6b/`, which is not under version control.
